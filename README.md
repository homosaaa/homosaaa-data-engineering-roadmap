# Data Engineering Mentorship Roadmap

A structured learning roadmap for the Data Engineering Mentorship Program, covering the core resources and additional materials across SQL, Python, Data Warehousing, Data Modeling, and Cloud fundamentals.

## Roadmap

1. **SQL**
2. **Python**
3. **Data Warehousing / Data Modeling**
4. **Cloud Services**

---

## Resources

### 1. SQL

* [Learn SQL Beginner to Advanced in Under 4 Hours](https://www.youtube.com/watch?v=OT1RErkfLNQ)

### 2. Python

* [CS50's Introduction to Programming with Python | Harvard University](https://pll.harvard.edu/course/cs50s-introduction-programming-python)

### 3. Data Warehousing / Data Modeling

* [Data Warehouse - The Ultimate Guide](https://www.udemy.com/course/data-warehouse-the-ultimate-guide/)
* [Data Warehousing Concepts: Common Processes | Databricks](https://www.databricks.com/discover/data-warehousing-concepts)
* [Data warehousing architecture | Databricks on AWS](https://docs.databricks.com/aws/en/sql/get-started/data-warehousing-concepts)
* [What is Databricks? | Databricks on AWS](https://docs.databricks.com/aws/en/introduction/)

### 4. Cloud Services

* [Ultimate AWS Certified Cloud Practitioner CLF-C02 2026](https://www.udemy.com/course/aws-certified-cloud-practitioner-new/)
* [Learn Databricks - Training & Resources](https://www.databricks.com/learn)

## Additional Resources

### Git & GitHub

* [Complete Git and GitHub Tutorial For Data Engineers](https://www.youtube.com/watch?v=Kr8l7rQGwNs)

Covers Git fundamentals, repositories, commits, branches, merging, merge conflicts, rebasing, stashing, cherry-picking, GitHub, cloning, and feature branches.

### Docker

* [Learn Docker - Full DevOps Course for Deploying Containerized Apps](https://www.youtube.com/watch?v=rjjES5IsPdg)

Covers Docker fundamentals, images, containers, networking, volumes, Dockerfiles, Docker Compose, registries, and containerizing applications.

### Data Engineering Learning Channels

* [DataExpert - YouTube](https://www.youtube.com/@EcZachly_/videos)
* [Seattle Data Guy - YouTube](https://www.youtube.com/@SeattleDataGuy/videos)
* [The Data and AI Guy - YouTube](https://www.youtube.com/@thedataandaiguy/videos)

### Data Engineering Practice / Extended Learning

* [Data Engineering Zoomcamp](https://github.com/DataTalksClub/data-engineering-zoomcamp)

A free, hands-on Data Engineering course covering areas such as workflow orchestration, data warehousing, analytics engineering, batch processing, streaming, and a final project.
